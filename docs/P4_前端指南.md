## 1. 后端对接契约（先记牢，下面代码都照这个写）

后端默认端口 `8000`，但**本机 8000 被别的程序占了，开发用 `8001`**。
前端访问地址统一写成 `http://localhost:8001`（下面用常量 `API_BASE` 统一管理，换端口只改一处）。

| 方法 | 路径 | 请求 | 响应 / 推送 | 用途 |
|---|---|---|---|---|
| POST | `/api/task/create` | `{material_name, purchase_quantity, expect_delivery_date, budget_limit}` | `{task_id}` | 创建采购任务 |
| GET | `/api/task/{task_id}` | — | `{task_id, status, solution, db_status}` | 查任务终态与最终方案 |
| GET | `/api/sse/task/{task_id}` | SSE 长连接 | 逐条推 `{event, data}` | 直播主图节点进度 |
| GET | `/api/sse/qa?question=xxx` | SSE 长连接 | 逐条推 `{event, data}` | 悬浮助手问答 |
| GET | `/health` | — | `{status:"ok"}` | 探活 |

**SSE 推送的 `event` 取值（重点，前端按它分支）：**

- 任务频道 `/api/sse/task/{id}`：
  - `status` → `data: "running"`（开工）
  - `node`   → `data: "<节点名>"`（orchestrator / market_intelligence / cost_calculate / negotiation / supplier_counter / reflector / risk_approval …）
  - `done`   → `data: "completed" | "blocked" | "manual"`（终态）
  - `error`  → `data: "失败原因"`
  - `end`    → `data: "done"`（连接关闭信号，见到就停止监听）
- 问答频道 `/api/sse/qa`：
  - `route`   → `data: 路由结果（命中哪类知识）`
  - `answer`  → `data: 回答正文`
  - `sources` → `data: 溯源列表`
  - `end`     → `data: "done"`

> ⚠️ 后端把整条事件包了一层：`data` 字段里是一个 **JSON 字符串**。
> 所以前端要 `JSON.parse(e.data)` 拿到 `{event, data}`，再读里面的 `event` 和 `data`。下面代码都这么写。

### 4.2 `vite.config.js` —— 开发服务器配置

```js
import { defineConfig } from 'vite'        // Vite 配置函数
import vue from '@vitejs/plugin-vue'        // Vue 插件，让 .vue 能被编译

export default defineConfig({
  plugins: [vue()],                         // 注册 Vue 插件
  server: {
    port: 5173,                             // 前端开发端口（后端 8001，跨域已在后端放行 *）
    proxy: {                                // 代理：前端发 /api 自动转发到后端 8001，省得写完整域名
      '/api': {
        target: 'http://localhost:8001',    // 后端地址（8000 被占用，用 8001）
        changeOrigin: true                  // 改写请求头里的 host，后端才认
      }
    }
  }
})
```

> 用了上面的 `proxy` 后，前端代码里写 `/api/task/create` 即可，Vite 自动转去 8001。
> **但 SSE 的 `EventSource` 不吃代理转发里的某些头**，所以问答/任务直播我们直接写完整地址 `http://localhost:8001/api/sse/...`，不走 `/api` 代理。下面代码就是这么写的。

## 6. 灵犀仔悬浮助手 `src/components/LingxiZai.vue`

> 这是定稿形象：**极光发光核**。点一下右下角发光核 → 右侧滑出问答窗 → 走 `/api/sse/qa` 实时收回答。

```vue
<script setup>
import { ref, onBeforeUnmount } from 'vue'   // ref=响应式变量；onBeforeUnmount=组件销毁时清理

const API_BASE = 'http://localhost:8001'      // 后端基地址（8001 端口）
const open = ref(false)                       // 问答窗是否展开（false=收起）
const messages = ref([                        // 聊天记录，每条 {role:'bot'|'user', text}
  { role: 'bot', text: '你好，我是灵犀仔 ✨ 需要比价、查供应商资质还是看行情？' }
])
const input = ref('')                         // 输入框绑定的文字
const sources = ref([])                       // 当前回答的溯源列表（渲染成来源卡片）
let es = null                                 // EventSource 实例（长连接），关窗时要关掉

// 发送问题：建一条 SSE 长连接，按 event 类型把回答/溯源塞进聊天记录
function ask() {
  const q = input.value.trim()               // 取输入并去首尾空格
  if (!q) return                             // 空问题不发了
  messages.value.push({ role: 'user', text: q })  // 先把用户这句显示出来
  input.value = ''                           // 清空输入框
  messages.value.push({ role: 'bot', text: '思考中…' }) // 先占个“正在想”的气泡

  // 断开上一条还没关的连接，避免叠连接
  if (es) es.close()
  // 建立 SSE：问号后面拼 question 参数（中文要 encodeURIComponent）
  es = new EventSource(`${API_BASE}/api/sse/qa?question=${encodeURIComponent(q)}`)

  sources.value = []                         // 新问题先清掉上一条的来源卡片
  let answerText = ''                        // 回答正文（后端整条推，前端负责打字机播放）
  // 后端每条推送都进 onmessage，data 是 JSON 字符串，必须 parse
  es.onmessage = (e) => {
    const evt = JSON.parse(e.data)           // 解析出 {event, data}
    if (evt.event === 'route') {             // 路由：命中哪类知识（这里只在控制台留痕）
      console.log('路由:', evt.data)
    } else if (evt.event === 'answer') {     // 回答正文：接住全文，打字机逐字放（流式观感）
      answerText = String(evt.data)
      typeOut(answerText)                    // 打字机播放，函数见下方
    } else if (evt.event === 'sources') {    // 溯源：存起来，模板里渲染成“来源卡片”
      sources.value = Array.isArray(evt.data) ? evt.data : [String(evt.data)]
    } else if (evt.event === 'end') {        // 结束信号：关连接
      es.close(); es = null
    }
  }
  es.onerror = () => {                        // 连接出错也关掉，避免一直重连
    es.close(); es = null
  }
}

// —— 打字机效果：把整段回答逐字“打”到最后一个气泡（对标 PROJECT.md §6.1-2 流式输出） ——
let timer = null                              // 打字机定时器句柄
function typeOut(full) {
  const idx = messages.value.length - 1       // 最后那个“思考中…”气泡
  let i = 0                                   // 已显示到第几个字
  clearInterval(timer)                        // 防上一次打字没停就叠加
  timer = setInterval(() => {                 // 每 24ms 放出 2 个字
    i = Math.min(i + 2, full.length)
    messages.value[idx] = { role: 'bot', text: full.slice(0, i) }
    if (i >= full.length) clearInterval(timer) // 全部放完就停表
  }, 24)
}

const quick = ['预算超了怎么办', '查螺纹钢历史价格', '供应商资质怎么查']  // 快捷指令预置问题
function quickAsk(q) { input.value = q; ask() }  // 一键把预置问题填进输入框并直接发送

function toggle() {                           // 点发光核：展开/收起
  open.value = !open.value
  if (!open.value && es) { es.close(); es = null }  // 收起时顺便关连接
}
onBeforeUnmount(() => { if (es) es.close(); clearInterval(timer) }) // 组件销毁时关连接+停打字机，防内存漏
</script>

<template>
  <!-- 右下角固定定位的悬浮容器 -->
  <div class="fixed bottom-6 right-6 z-50 flex items-end gap-3">

    <!-- 问答窗：open 为真才显示（宽度过渡做出滑入感） -->
    <div v-if="open"
         class="w-80 bg-surface rounded-3xl shadow-2xl border border-black/5 p-4 mb-2">
      <h2 class="font-bold text-ink">灵犀仔 · 悬浮助手</h2>
      <p class="text-xs text-muted mb-2">实时对接 /api/sse/qa</p>
      <!-- 聊天记录区，每条按角色决定左右和气泡色 -->
      <div class="h-64 overflow-y-auto space-y-2 text-sm">
        <div v-for="(m, i) in messages" :key="i"
             :class="m.role === 'user' ? 'text-right' : 'text-left'">
          <span :class="m.role === 'user'
                  ? 'inline-block bg-accent/15 rounded-2xl rounded-tr-sm px-3 py-2'
                  : 'inline-block bg-bg rounded-2xl rounded-tl-sm px-3 py-2 whitespace-pre-line'">
            {{ m.text }}
          </span>
        </div>
      </div>
      <!-- 快捷指令：一键发起常见查询（对标 PROJECT.md §6.1-2 快捷指令） -->
      <div class="flex flex-wrap gap-1 mb-2">
        <button v-for="q in quick" :key="q" @click="quickAsk(q)"
                class="text-xs rounded-full bg-bg border border-black/10 px-2 py-1 text-muted hover:border-accent hover:text-accent">
          {{ q }}
        </button>
      </div>
      <!-- 来源卡片：回答带溯源时展示（对标 PROJECT.md §6.1-2 溯源卡片） -->
      <div v-if="sources.length" class="mt-2 space-y-1">
        <div v-for="(s, i) in sources" :key="i"
             class="text-xs bg-bg rounded-lg px-2 py-1 border border-black/5 truncate" :title="s">
          📚 {{ s }}

      </div>
      <!-- 输入行：回车或点发送都调用 ask() -->
      <div class="mt-2 flex gap-2">
```

## 8. 任务控制台 `src/components/TaskConsole.vue`

> 填表创建任务 → 拿 `task_id` → 订阅 `/api/sse/task/{id}` 直播 8 节点 → 每收到 `node` 就通知看板加一块。

```vue
<script setup>
import { ref } from 'vue'
import axios from 'axios'                            // HTTP 客户端（创建任务用）

const API_BASE = 'http://localhost:8001'            // 后端基地址

// 表单字段，初值给个示例方便测试
const form = ref({
  material_name: '螺纹钢',                           // 采购物料（与行情 CSV 品种名一致）
  purchase_quantity: 1000,                          // 数量（吨）
  expect_delivery_date: '2026-10-15',               // 期望交付
  budget_limit: 4200000                            // 预算红线（元）
})
const status = ref('idle')                          // idle / running / completed / blocked / manual / failed
const log = ref([])                                // 直播日志：每收到一条事件 push 一行
let es = null                                      // 任务 SSE 连接

// 创建任务并开直播
async function start() {
  // 1) 调后端创建任务，拿到 task_id
  const { data } = await axios.post(`${API_BASE}/api/task/create`, form.value)
  const taskId = data.task_id
  status.value = 'running'
  log.value = [`已创建任务 ${taskId}`]

  // 2) 开 SSE 长连接订阅进度
  if (es) es.close()
  es = new EventSource(`${API_BASE}/api/sse/task/${taskId}`)

  es.onmessage = (e) => {
    const evt = JSON.parse(e.data)                 // {event, data}
    if (evt.event === 'status') {
      log.value.push(`状态：${evt.data}`)           // running
    } else if (evt.event === 'node') {
      log.value.push(`✅ 节点完成：${evt.data}`)     // 某个业务节点跑完
      // 用 window 自定义事件通知 Dashboard 点亮工作流时间线（跨组件解耦，不用传 ref）
      window.dispatchEvent(new CustomEvent('agent-node', { detail: evt.data }))
    } else if (evt.event === 'done') {
      status.value = evt.data                       // completed / blocked / manual
      log.value.push(`🏁 终态：${evt.data}`)
      window.dispatchEvent(new CustomEvent('agent-risk', { detail: evt.data })) // 通知风险面板
    } else if (evt.event === 'error') {
      log.value.push(`❌ 出错：${evt.data}`)
    } else if (evt.event === 'end') {
      es.close(); es = null                         // 收工
    }
  }
}

// 人工干预入口（审批接口 P5 在后端补 POST /api/task/{id}/approve 后接通）
function approve() { log.value.push('（演示）人工审批通过——接口待 P5 接通') }
function rerun()    { log.value.push('（演示）调整参数重跑——请修改表单后再点启动') }
</script>

<template>
  <div class="bg-surface rounded-3xl shadow p-4">
    <h2 class="font-bold text-ink mb-3">创建采购任务</h2>
    <!-- 表单：每个 input 用 v-model 双向绑定到 form -->
    <div class="grid grid-cols-2 gap-3 text-sm">
      <label class="flex flex-col gap-1">
        <span class="text-muted">物料</span>
        <input v-model="form.material_name" class="rounded-lg border border-black/10 px-3 py-2 outline-none focus:border-accent" />
      </label>
      <label class="flex flex-col gap-1">
        <span class="text-muted">数量(吨)</span>
        <input v-model.number="form.purchase_quantity" type="number" class="rounded-lg border border-black/10 px-3 py-2 outline-none focus:border-accent" />
      </label>
      <label class="flex flex-col gap-1">
        <span class="text-muted">期望交付</span>
        <input v-model="form.expect_delivery_date" class="rounded-lg border border-black/10 px-3 py-2 outline-none focus:border-accent" />
      </label>
      <label class="flex flex-col gap-1">
        <span class="text-muted">预算(元)</span>
        <input v-model.number="form.budget_limit" type="number" class="rounded-lg border border-black/10 px-3 py-2 outline-none focus:border-accent" />
      </label>
    </div>
    <button @click="start"
            class="mt-3 rounded-full bg-accent px-5 py-2 font-bold text-[#06343a]">
      启动任务并直播
    </button>
    <!-- 人工干预入口（对标 PROJECT.md §6.1-1）：任务被拦/需人工时才出现 -->
    <div v-if="status === 'manual' || status === 'blocked'" class="mt-2 flex items-center gap-2">
      <button @click="approve" class="rounded-full border border-accent px-4 py-1.5 text-sm font-bold text-accent">人工审批通过</button>
      <button @click="rerun" class="rounded-full border border-black/10 px-4 py-1.5 text-sm text-muted">调整参数重跑</button>
      <span class="text-xs text-muted">审批接口 P5 补 POST /api/task/{id}/approve 后接通</span>
    </div>

    <!-- 直播日志：自动滚到底 -->
    <div class="mt-3 h-40 overflow-y-auto bg-bg rounded-xl p-3 text-xs space-y-1">
      <div v-for="(line, i) in log" :key="i">{{ line }}</div>
```

## 10. 真实数据导出脚本（一次性，把 CSV 变 JSON 放 public/）

在项目根目录跑这段 Python（用项目 Python 环境），从已有 CSV 产出前端要的 JSON：

```python
import csv, json, os

# 行情：commodity_price.csv → public/market.json
# 真实列名：commodity_name(中文品种) / price(收盘价) / record_date(交易日)；文件带 BOM，用 utf-8-sig 读
rows = []
with open('seed_data/commodity_price.csv', encoding='utf-8-sig') as f:
    for r in csv.DictReader(f):
        rows.append({
            'commodity': r['commodity_name'],   # 品种中文名：螺纹钢/铝/铜/LLDPE
            'date': r['record_date'],           # 交易日
            'close': float(r['price'])          # 收盘价
        })
os.makedirs('frontend/public', exist_ok=True)
with open('frontend/public/market.json', 'w', encoding='utf-8') as f:
    json.dump(rows, f, ensure_ascii=False)

# 供应商：supplier.csv → public/suppliers.json
# 真实列名：supplier_name / credit_status(A/B/C 等级) / premium_rate(溢价系数) / main_category
CREDIT_MAP = {'A': 95, 'B': 75, 'C': 55}                     # 等级 → 信用分（0~100）
sup = []
with open('seed_data/supplier.csv', encoding='utf-8-sig') as f:
    for r in csv.DictReader(f):
        sup.append({
            'name': r['supplier_name'],                                # 企业名
            'credit': CREDIT_MAP.get(r['credit_status'], 60),          # 等级转分数
            'premium': round((float(r['premium_rate']) - 1) * 100, 2)  # 溢价系数 1.045 → 溢价率 4.5%
        })
with open('frontend/public/suppliers.json', 'w', encoding='utf-8') as f:
    json.dump(sup, f, ensure_ascii=False)
print('导出完成：market.json / suppliers.json')
```
